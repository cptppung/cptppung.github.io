GCP(Google Gloud Platform)라고 많이 불리었으나 현재는 Google에서 점차 Platform라는 단어를 없애고 있다.

[google cloud 자격증 소개](https://cloud.google.com/learn/certification?hl=ko)글을 보면 Cloud Architect, Cloud Database Engineer, Cloud Developer, Data Engineer등이 있고, 여기에서 Foundational, Associate, Professional로 난이도가 나뉘는게 아닌 각각 자격증의 종류별로 난이도에 속하게 된다.

Cloud Architect를 도전하려고 하며 이에 대한 여정을 남기려하니 도움이 되는 분들이 있으면 하며 글을 작성하려는데...
